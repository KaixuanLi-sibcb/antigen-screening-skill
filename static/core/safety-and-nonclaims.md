# Safety And Nonclaims

This skill supports research prioritization only. It does not establish clinical safety, efficacy, or patient treatment suitability.

## Nonclaims

- A `go` call is not a clinical recommendation.
- A high tie-break score is not proof of safety.
- RNA expression is not protein surface localization.
- Approved drug evidence is not automatically positive.
- Fixture smoke-test evidence is not live database verification.

## Data Handling

Do not write tokens, credentials, API keys, cookies, private identifiers, or unpublished sensitive data into reports, logs, or Git commits.
