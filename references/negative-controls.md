# Negative And Sanity Controls

Controls are required because antigen-screening logic can otherwise pass superficial candidates.

## ALB

ALB is secreted and extracellular, so it should not fail every antigen concept. It can be a soluble protein control. However, it should not be treated as a transmembrane CAR-T or ADC cell-surface target, and high liver/plasma abundance is a major risk flag.

## MKI67

MKI67 is a nuclear proliferation marker. It may be useful in expression analyses, but it must fail surface-antigen accessibility for antibody/CAR/ADC surface targeting and must not receive an ECD construct.

## Why Include Both

ALB tests modality-specific handling of secreted proteins. MKI67 tests hard failure for intracellular/nuclear markers.
